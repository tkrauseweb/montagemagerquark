# Montagemagerquark

Eine humorvolle, responsive One-Page-Website rund um den fiktiven „Montagemagerquark“ – gestaltet im industriellen Retro-Look.

## Funktionen

- responsive Darstellung für Smartphone und Desktop
- animierte Plakate, Nährwertzähler und Scroll-Effekte
- aufklappbare Rezepte
- interaktiver „Quarkomat 84“
- wechselnder „Quark des Tages“

## Lokal starten

```bash
python3 -m http.server 8000
```

Anschließend `http://localhost:8000` im Browser öffnen.

Die Website ist ein fiktives Gestaltungskonzept. Die dargestellten Nährwerte und Produkte sind keine echten Produktangaben.
